# British Cinema deploy + serve on titan

This project folder is the **deployment + serving layer** for the British Cinema catalogue site. The build pipeline lives separately in `../kometa/posters/`.

## Where things actually live

| Concern | Path | Notes |
|---|---|---|
| Build scripts | `/home/stu/projects/kometa/posters/*.py` | Python; canonical entry: `build_site.py` |
| Build data | `/home/stu/projects/kometa/posters/data/all.json`, `bios.json`, `tmdb_map.json` | Generated by upstream fetchers |
| Build output (staging) | `/home/stu/projects/kometa/posters/site/` | Mirror of what gets deployed |
| Deployed site | `/var/www/british-cinema/` | Read by tailscale serve |
| Public URL | `https://titan.tail1a2109.ts.net/british-cinema/` | Tailnet only |

## Build trigger

```bash
cd /home/stu/projects/kometa/posters
python3 build_site.py        # reads data/*.json, writes site/
```

Then deploy:

```bash
sudo rsync -a --delete /home/stu/projects/kometa/posters/site/ /var/www/british-cinema/
```

`./deploy.sh` here wraps both steps. Use it.

## Serving

Static files served via `tailscale serve` (NOT nginx for this path). Confirm with:

```bash
tailscale serve status
# Should show:
# https://titan.tail1a2109.ts.net (tailnet only)
# |-- /                proxy http://127.0.0.1:18789
# |-- /british-cinema/ path  /var/www/british-cinema
```

## Don't accidentally

- **Replace the tailscale serve binding wholesale.** It also serves `/` → OpenClaw (`:18789`). Only add or remove specific paths via `tailscale serve --set-path /<x> <target>` / `tailscale serve --remove-path /<x>`.
- **Edit files under `/var/www/british-cinema/` directly.** They get blown away on next `deploy.sh`. Edit the templates in `kometa/posters/` instead.
- **`rsync --delete` without checking the source path** — typo'ing the source side could blank /var/www/british-cinema.

## Common operational queries

```bash
./status.sh                                    # last build time + tailscale serve config
ls /home/stu/projects/kometa/posters/site/     # staging output
ls /var/www/british-cinema/                    # deployed
sudo stat /var/www/british-cinema/index.html   # last deploy time
```
